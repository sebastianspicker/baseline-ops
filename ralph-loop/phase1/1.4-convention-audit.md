## Prioritized Remediation Plan

### Priority 1: Systemic issues (affect nearly all scripts)

1. **C9 Output contract**: 47 scripts need `New-V2ResultObject` + `Write-ResultObject`. This requires importing `Serialization.psm1` and wrapping the final result.
2. **C11 Exit code**: 41+ scripts need `exit 0` at the end (or conditional exit logic).

### Priority 2: Moderate issues (affect ~20 scripts each)

3. **C5 StrictMode**: 22 scripts need `Set-StrictMode -Version Latest` (upgrade from 2.0/3.0).
4. **C10 Findings pattern**: 22 feature scripts need `New-FindingsList` / `Add-Finding` adoption (requires importing Results.psm1).

### Priority 3: Smaller gaps

5. **C6 ErrorActionPreference**: 10 scripts need `$ErrorActionPreference = 'Stop'`.
6. **C3/C4 Bootstrap/Imports**: 1 script (00-Run-Batch.ps1) is missing Bootstrap and module imports.
7. **C7 Comment-based help**: 2 scripts (00-Report-Aggregate, 00-Run-Batch) are missing `.DESCRIPTION`.
