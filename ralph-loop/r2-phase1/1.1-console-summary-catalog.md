# R2 Phase 1.1 -- Write-ConsoleSummary / Get-StatusColor Variant Catalog

## Canonical Implementations (lib/Console.psm1)

### Get-StatusColor (line 60)
- **Parameters**: `[string]$Status` (Mandatory)
- **Behavior**: Normalizes status keywords via regex switch (Critical/High/Medium/Low/OK/Skip etc.) then delegates to `Get-SeverityColor`
- **Returns**: ConsoleColor string (e.g. `'Red'`, `'Yellow'`, `'Green'`)

### Write-ConsoleSummary (line 283)
- **Parameters**: `[psobject]$Summary`, `[System.Collections.ArrayList]$Findings`, `[string]$Title`, `[int]$Width`
- **Renders**: ComputerName, Timestamp, Duration (if StartTime/EndTime present), FindingsCount, then iterates Findings calling `Write-FindingLine` for each
- **Format**: Decorative rule header, key-value pairs, severity-colored finding lines

## Proposed Lib Enhancements for "Adaptable" Scripts

### 1. Write-ConsoleSummary enhancements

**A. `CustomFields` parameter (hashtable or ordered dictionary)**
Allows scripts to inject domain-specific key-value lines after the standard header (ComputerName, Timestamp, FindingsCount).

Would benefit: 33-AdvancedAuditPolicy (DesiredPolicySource), 34-TimeSync (W32TimeServiceState, NTP config), 41-NTLM (LmCompatibilityLevel).

**B. `CustomSections` parameter (array of section objects)**
Each section = `@{ Title = '...'; Lines = @( @{ Key = '...'; Value = '...'; Color = '...' }, ... ) }`.

Would benefit: 27-Defender-Health (Core status, Ages, Tamper, Meta sections), 31-PowerShell-Logging (target settings, effective policy sections), 36-Backup-Readiness (Indicators section).

**C. Extended finding display (Evidence, Remediation sub-fields)**
Add optional sub-line rendering in `Write-FindingLine` when finding has Evidence or Remediation properties.

Would benefit: 36-Backup-Readiness.

**D. `UseWriteInformation` switch**
Route all output through Write-Information when set, for scripts that need Information stream output.

Would benefit: 34-TimeSync-Health.

### 2. Get-StatusColor enhancements

**A. Add "Note" keyword mapping**
Add `'^(Note)$' { 'Info' }` (or map to DarkGray directly) in the regex normalizer.

Would benefit: 18-Firewall-Baseline.

## Key Observations

1. **No drop-in replacements exist** for Write-ConsoleSummary. Every local implementation adds at least some domain-specific rendering.

2. **Most incompatible scripts (15/21)** have fundamentally different data models -- they do not use severity-based Findings at all, or they render domain-specific collections (disks, interfaces, shares, drift items, software inventories).

3. **The 6 adaptable scripts** all share the pattern of: standard Summary object with ComputerName/Timestamp + ArrayList/List of Findings with Severity/Code/Message + some extra domain fields or sections.

4. **Get-StatusColor** in 08-WinGet-SelfHeal is the only near-drop-in replacement; the one in 23-BitLocker has a completely different signature (maps domain values like FullyEncrypted, not status keywords).

5. **Estimated effort**: Adding `CustomFields` + `CustomSections` parameters to the lib Write-ConsoleSummary would make the 6 adaptable scripts replaceable. This is a moderate change (~30-50 lines of lib code) that would eliminate 6 local implementations.
