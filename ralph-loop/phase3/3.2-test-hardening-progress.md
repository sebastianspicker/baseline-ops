## Known Limitation Found

`Write-PrettySummary` passes `@()` to `Write-ConsoleSummary -Findings [ArrayList]`, which PowerShell rejects because it cannot bind an empty collection to the `[System.Collections.ArrayList]` type. This is a source code limitation documented via a test assertion.
