## Notes

- The `$null`-to-empty-string coercion in PowerShell means that passing `$null` to `[AllowNull()][string]$Path` still results in an empty string at the callee boundary. Tests for Config.psm1 work around this by testing with nonexistent file paths rather than null paths.
- EventLog tests are fully skipped on non-Windows since they depend on `[System.Diagnostics.EventLog]` and `Write-EventLog`.
- External.psm1 Windows-only tests (Invoke-Wevtutil, New-ScheduledTask) are skipped on macOS.
- Output.psm1 tests use `Mock Write-Host -ModuleName Output` to intercept calls within the module scope.
