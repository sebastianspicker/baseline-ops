## What Was NOT Touched

- The 15 "Incompatible" scripts (keep their local versions)
- lib/Console.psm1 (already enhanced in Phase 2.1)
- Script business logic (only console output functions removed/replaced)

## Trade-offs

The lib Write-ConsoleSummary renders flat key-value custom fields in Gray color.
Scripts that previously had:
- Per-field conditional coloring (boolean green/red, severity colors)
- Sub-section headers (Core status, Ages, Meta)
- Evidence/Remediation sub-lines per finding
- UseWriteInformation routing
- Severity breakdown counts

...now lose that visual richness in exchange for consistency and code deduplication.
Net reduction: ~330 lines removed across 7 scripts.
