## Migration Pattern Summary

All migrated scripts follow this pattern:
1. `Import-Module Results.psm1`
2. `$script:Findings = New-FindingsList`
3. Populate findings via `Add-Finding -FindingList $script:Findings -Code '...' -Severity '...' -Message '...'`
4. V2 result: `-Findings @($script:Findings)`

For hard scripts with existing string-based drift collections, the approach preserves backward compatibility by keeping the legacy collections and converting to canonical findings at the end (before v2 result).
