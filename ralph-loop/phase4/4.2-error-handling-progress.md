# Phase 4.2 -- Error Handling Standardization Progress

> Started: 2026-03-21
> Reference: scripts/34-TimeSync-Health.ps1

## Standard Pattern

1. `$ErrorActionPreference = 'Stop'` + `Set-StrictMode -Version Latest` at script top
2. Major operation blocks wrapped in `try { ... } catch { ... }`
3. Catch blocks use `Add-Finding` / `Write-Warning` -- never swallow silently
4. Resource cleanup in `finally` blocks when temp files/registry are involved
5. Script exit uses v2 result object with `Result = 'FAIL'` on errors, not bare `throw`
