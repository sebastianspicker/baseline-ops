## Not changed (intentionally)

- **Local `Save-Json` in scripts 04, 06, 07, 11, 12, 15**: Different parameter names (`-Obj`/`-Object` vs lib's `-InputObject`), varying depth values, and some return `$true`/`$false`. Updating all callers within each script would be a larger refactor beyond lib-module dedup scope.
- **`Write-JsonFile` in script 17**: Returns `$true`/`$false` (caller checks return value). Different semantic contract from `Save-Json` which throws on error.
- **Local JSON readers in scripts 13, 16, 21, 22, 27**: These have more complex semantics (merge defaults, config-specific logic). Would need case-by-case analysis.
- **`Expand-EnvPath` in script 18**: Different name, slightly different semantics from `Expand-Env`.
